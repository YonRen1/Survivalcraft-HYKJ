

# HYKJ 荒野科技模组 (Survivalcraft2-HYKJ)

## 📌 模组简介

荒野科技（HYKJ）是一款基于[生存战争插件版 API](https://gitee.com/SC-SPM/SurvivalcraftApi/) SCAPI1.9开发的开放世界生存模组，始创于2023年10月，历经多次迭代优化，现已成为一款内容丰富、玩法多样的生存类模组。

在游戏中，玩家将扮演一名被海盗流放至荒岛的海难者，手无寸铁地从原始人开始重新发育。模组以前期拓展为核心玩法，通过收集资源、打造工具、建造设施，最终在这片荒岛上生存下去。

### 核心特色

- **生存挑战**：从零开始，步步为营的生存体验
- **丰富物品**：数百种新材料、工具、武器和装备
- **多样化玩法**：种植、烹饪、冶炼、建造等多种玩法
- **汉化支持**：完整的中文语言包，贴近母语体验
- **持续更新**：活跃的开发团队，定期更新内容

## 🛠️ 模组架构

| 项目 | 版本 |
|------|------|
| API版本 | 2.4 API1.9 |
| .NET版本 | 9.0 |
| 开发平台 | C# (Termux/MT管理器/Visual Studio/Rider) |

### 主要组件

- **方块系统**：定制化方块类型（扁平方块、镐类、斧类、 Machete 类等）
- **GUI系统**：自定义界面组件、玩家信息展示
- **合成系统**：工作台、炼焦炉等合成机制
- **对话框系统**：版本更新提示、游戏内公告
- **材质系统**：自定义纹理和3D模型支持

## 🔧 使用说明

### 前置要求

1. 安装生存战争插件版（SC-SPM/SurvivalcraftApi）
2. 确保游戏版本与模组兼容
3. 推荐NET 9.0运行环境

### 安装方法

1. 从发行版本下载正式模组包
2. 将模组文件放入游戏的Mods文件夹
3. 启动游戏，在模组列表中启用HYKJ模组
4. 创建新世界开始游戏

### 游戏提示

- 模组以前期发展为主题，建议新手玩家先熟悉基础合成
- 加入官方交流群获取更多游戏攻略
- 遇到问题可查看FAQ或联系开发者

## 💻 模组开发

### 开发环境

**移动端开发**：
- 使用Termux安装Git
- 克隆本仓库到本地
- 使用C# Shell或MT管理器进行代码修改

**桌面端开发**：
- 使用Git克隆仓库
- 推荐IDE：Visual Studio 或 JetBrains Rider
- 支持断点调试和代码补全

### 构建说明

1. 克隆项目仓库
2. 使用IDE打开解决方案文件
3. 配置.NET 9.0编译环境
4. 编译生成DLL文件
5. 将编译产物放入游戏Mods目录测试

### 代码结构

```
HYKJMod/
├── Block/           # 方块实现
├── Component/       # 游戏组件
├── Dialog/          # 对话框系统
├── Subsystem/       # 子系统处理
├── Widget/          # UI组件
├── MOD/Assets/      # 资源文件
│   ├── HYKJTextures/  # 纹理资源
│   ├── Models/        # 3D模型
│   ├── Lang/          # 语言包
│   └── CraftingRecipes.xml  # 合成配方
└── ModLoader.cs     # 模组入口
```
